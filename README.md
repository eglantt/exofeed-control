# ExoFeed Control

Приложение для учёта кормления и линьки животных в террариумном хозяйстве. Работает полностью в браузере, без сервера и без интернета (кроме самой первой загрузки страницы) — вся база хранится локально в браузере устройства (`localStorage`).

Текущая версия: **v1.8.0-alpha**.

### Что нового в v1.8.0

- Новая функция **«Инкубация»**: блок-стеллаж типа «Инкубатор» (ячейки которого вмещают только кладки, не животных), карточка кладки (дата откладки, количество яиц, статус, привязка родителя из базы или текстом), отдельный журнал температуры и влажности у кладки, фиксация частичного/полного вылупления и гибели, архив завершённых кладок, отчёт по инкубации (сроки, % вылупляемости) — доступен через кнопку «🥚 Инкубация» в нижней навигации.
- Бэкап/импорт теперь включает архив кладок наравне с архивом животных.
